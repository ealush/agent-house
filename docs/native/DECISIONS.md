# Decisions

Prepared 23 October 2026. Product choices below come from the supplied mission, not an independently chosen replacement stack.

| Decision | Reason and reference |
| --- | --- |
| iOS/iPadOS 26+, Swift 6 | Required by the port kit. No old-iOS compatibility paths. Xcode 26+ is needed for compilation. |
| UIKit application/scene delegates (coordinator superseded below) | UIKit owns windows, navigation and restoration; SwiftUI content is hosted using [UIHostingController](https://developer.apple.com/documentation/swiftui/uihostingcontroller). Follow [UISceneDelegate](https://developer.apple.com/documentation/uikit/uiscenedelegate) and [state restoration](https://developer.apple.com/documentation/uikit/restoring-your-app-s-state). |
| Observation + structured concurrency | A scene's UI model is MainActor-isolated. Persistence is actor-isolated; no Combine state graph. [Apple Observation](https://developer.apple.com/documentation/observation). |
| GRDB 7.11.1, exact pin | Selected by the supplied specification; the version was verified against the upstream release API. [Release](https://github.com/groue/GRDB.swift/releases/tag/v7.11.1), [tagged package manifest](https://github.com/groue/GRDB.swift/blob/v7.11.1/Package.swift). No other persistence framework. |
| DatabasePool + migrations | A shared journal serves independent windows; WAL readers and explicit transactions keep ownership clear. [GRDB documentation](https://github.com/groue/GRDB.swift/blob/v7.11.1/README.md#database-connections). |
| XcodeGen spec as project authority | Reproducible native target/test configuration without hand-authoring pbxproj identifiers on Linux. [Project specification](https://github.com/yonaskolb/XcodeGen/blob/master/Docs/ProjectSpec.md). Generate on macOS; project generation has not been run here. |
| macOS 26 CI image | The authored simulator workflow uses the supported `macos-26` runner label from the official [runner image inventory](https://github.com/actions/runner-images#available-images). The workflow has not run. |
| HTTPS `.ts.net` hub on standard Serve port | Conservative current connection scope; validation is not authentication. Custom domains, ports and loopback HTTP are not implemented. Preview origins will have a separate policy. |
| Native auth remains a required backend contract | No forged browser Origin/Serve headers, CLI token reuse or insecure fallback. Designed and built 24 October (below). |
| Replaceable native terminal | Selected 24 October after the prototype below; originally: SwiftTerm is a candidate, not a verified selection. Prove Unicode/ANSI, IME, modifiers, selection, paste, mouse, resize, independent viewers and reconnect on iOS 26 before adding the dependency. [SwiftTerm upstream](https://github.com/migueldeicaza/SwiftTerm). |
| Preserve one canonical audit and spec | ZIP members equal loose documents byte for byte. Import their contents once as root AUDIT/SPEC with a short local scope/provenance preface. Do not copy the archive or legacy path aliases. |

Do not treat documentation research as proof that this app compiles or behaves correctly. Record new non-obvious API choices and simulator/device evidence here during implementation.

## Scaffolding — 24 October 2026

| Decision | Reason and reference |
| --- | --- |
| Foundation-only Swift Package test harness | Compile the same protocol sources and tests on Linux/macOS without introducing an alternative persistence/UI stack or copying implementations. The iOS app remains generated by XcodeGen. [Swift Package Manager](https://www.swift.org/documentation/package-manager/). |
| Strict API 28 read projection | Source `web/api.ts` declares version 28. Require this version and stable uids rather than silently synthesizing compatibility identities from tmux addresses. History, presets and review DTOs are later slices. |
| Connection-local snapshot/patch reducer | The audited stream has no revision counter; top-level field replacement matches `server/core.ts`. Explicit null differs from an omitted patch field. Corrupt events invalidate state pending resync. |
| Bounded incremental SSE decoding | Follow [WHATWG event-stream interpretation](https://html.spec.whatwg.org/multipage/server-sent-events.html#event-stream-interpretation), with configurable limits and deliberate rejection of malformed UTF-8. No live transport/authentication is implied. |


## Implementation — 24 October 2026

| Decision | Reason and reference |
| --- | --- |
| Device-key enrollment instead of passkeys on `.ts.net` | Passkeys need Associated Domains, which iOS 14+ fetches through Apple's CDN; a private tailnet host is unreachable from it (only the developer "alternate mode" bypasses the CDN), and every user has their own hostname, so no single entitlement could list them. [Supporting associated domains](https://developer.apple.com/documentation/xcode/supporting-associated-domains). Instead: a Secure Enclave P-256 key per device and host (`SecureEnclave.P256.Signing.PrivateKey`, `.userPresence` access control so each sign-in needs Face ID), enrolled with a one-time code from an already signed-in device, signing `ah-native-{enroll,login}-v1` messages over a fresh host challenge. Backend: `ah` branch `native/1-device-auth`. |
| Bearer sessions, no cookies | `URLSessionTransport` disables cookie storage, caching and redirects. Native writes send `Authorization: Bearer` + `X-AH`; the host accepts a missing Origin only for a native bearer with no Cookie header, so browser CSRF defenses stay intact. Revocation fails closed: any 401/4401 signs the account out everywhere. |
| APNs from the host, ES256 JWT over HTTP/2 | Token-based provider authentication ([Establishing a token-based connection to APNs](https://developer.apple.com/documentation/usernotifications/establishing-a-token-based-connection-to-apns)); the key file stays on the host (`config.apns`). Registrations belong to a native sign-in and vanish with it. Approve/Deny actions appear only for plain permission prompts, with `.authenticationRequired`. Backend: `ah` branch `native/2-apns`. |
| SwiftTerm 1.99.1 for the terminal | Validated against a real tmux session through the app's `TerminalConnection` on Linux (ANSI, wide glyphs, input, resize). Used through its public `TerminalView`/`TerminalViewDelegate` API; bracketed paste through `paste(_:)`. [SwiftTerm](https://github.com/migueldeicaza/SwiftTerm). |
| iOS 26 `updateProperties()` instead of Combine | UIKit tracks Observation reads in `updateProperties()` and re-runs it on change ([updateProperties()](https://developer.apple.com/documentation/uikit/uiviewcontroller/updateproperties())); the shell follows `SceneModel` with no publishers. |
| `UITab`/`UITabBarController(tabs:)` in the split's `.compact` column | One `UISplitViewController` per window adapts between iPad sidebar+detail and iPhone tabs ([UISplitViewController.Column.compact](https://developer.apple.com/documentation/uikit/uisplitviewcontroller/column/compact)); both read the same `SceneModel`, so resizing never loses the place. |
| Menu-bar commands validated by key scope | `UIKeyCommand`s live in the main menu (discoverable with ⌘-hold, rebuilt when bindings change via `UIMenuSystem.main.setNeedsRebuild()`); `canPerformAction` disables any command whose chord the focused composer/terminal owns, so the key falls through to it. Field-edge commands get no menu chord. |
| One module for Linux and Apple | `Package.swift` compiles every non-UI source as `AgentHubKit` so models, keyboard routing and persistence run in `swift test` and against a disposable `ah` in `scripts/integration.sh`. |
| Sealed cache: HKDF(device secret, per-sign-in server key, origin) + AES-GCM | A stolen database alone reveals nothing; locking forgets the key; a revoked sign-in's server key is gone so old rows are unreadable; forgetting an account deletes its rows. Only the newest transcript page per session is cached today (`HubStateDTO` is decode-only). |
| `agenthub://<host>/<route>` deep links | Same routes as push payloads (`<uid>`, `review/<stack>/<pr>`); only a uid-shaped path opens a session. No Universal Links (same Associated Domains limit as passkeys). |
| No fake progress or local "success" | Sends show `sending` until the host answers; refused sends return to the box; merges re-sync and stop if the head moved; "No checks reported" is shown as such, never as passing. |
